# Crisis Handoff Runbook

**Status:** v0.1 operational skeleton, not a full emergency response system.

This runbook defines the minimum behavior when `emotional_safety` reaches Level 3 or triage returns `crisis_intervention`.

## Trigger

Start crisis handoff when any of the following is true:

- `data/dimension_scores.*.dimensions.emotional_safety.level >= 3`
- `triage.should_escalate()` returns `escalation_type = crisis_intervention`
- profile `needs_signals` contains `crisis_intervention`
- profile `risk_flags` contains active self-harm, suicidal ideation, abuse signal, or severe bullying indicators

## What AI Must Stop Doing

Once Level 3 is detected, AI must stop:

- treating the situation as ordinary coaching, tutoring, or productivity support;
- promising confidentiality without qualification;
- asking the student to keep disclosing more sensitive details for analysis;
- negotiating with the student about whether escalation is "necessary";
- giving therapy-style crisis counseling as if it replaces a human;
- exposing raw student statements to parents, teachers, or tutors.

The AI may only:

- acknowledge the concern calmly;
- say that a trusted adult must review the situation;
- produce a brief abstract handoff note with no verbatim student quotes;
- remind the operator that this is a human-review case.

## What Human Must Review

A named human reviewer must inspect:

- the abstracted profile;
- the dimension scores and trend notes;
- the crisis trigger reason;
- the minimum necessary raw conversation context, if and only if the reviewer is authorized;
- whether immediate parent/guardian contact is appropriate;
- whether school counselor, external professional, or emergency service involvement is needed;
- whether the student is currently reachable and physically safe.

## Minimum Handoff Payload

The handoff packet is generated by `src/crisis_handoff.py`. It should include:

- student identifier or internal pseudonym;
- trigger type and timestamp;
- dimension score summary;
- non-verbatim description of concern;
- whether the concern appears acute, repeated, or worsening;
- recommended next human action;
- privacy note listing categories of details withheld from ordinary parent/teacher views.

It should not include:

- raw quotes;
- secret truths;
- scenario seeds;
- unnecessary names of third parties;
- detailed family events that allow reconstruction.
